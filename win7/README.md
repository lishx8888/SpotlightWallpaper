# Windows 7 微软聚焦壁纸自动设置工具

## 功能说明
- 自动从微软聚焦服务获取最新壁纸并下载
- 立即删除目录中除当前壁纸外的所有旧壁纸，只保留最新一张
- 无需管理员权限，普通用户双击即可运行
- 自动设置为桌面壁纸并立即生效

## 使用方法
1. 确保您的Windows 7系统已安装PowerShell 5.0或更高版本
2. 双击运行 `SpotlightAPIWallpaper.ps1` 脚本
3. 脚本将自动完成以下操作：
   - 创建壁纸保存目录（如果不存在）
   - 强制使用TLS 1.2协议确保下载成功
   - 获取最新壁纸URL
   - 下载壁纸到本地（固定文件名：壁纸.jpg）
   - 删除目录中所有旧壁纸
   - 设置为桌面壁纸并立即生效

## 脚本配置
脚本默认配置（无需修改即可使用）：
- 壁纸保存目录：`C:\Users\Administrator\Pictures\SpotlightWallpapers`
- 壁纸文件名：`壁纸.jpg`（固定名称，每次更新会覆盖）
- API地址：使用第三方服务获取微软聚焦壁纸

## 注意事项
1. 首次运行可能需要设置PowerShell执行策略：
   - 以管理员身份打开PowerShell
   - 执行命令：`Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope CurrentUser`
   - 输入 `Y` 确认

2. **特别提示**：
   - 脚本会立即删除保存目录中的所有旧壁纸，只保留最新下载的一张
   - 如果您需要保留历史壁纸，请在运行脚本前备份该目录

3. 如果下载失败，请检查：
   - 网络连接是否正常
   - 系统是否已更新到支持TLS 1.2的补丁

4. 壁纸设置完成后会立即生效，无需重启电脑

## 常见问题
### Q: 为什么双击脚本没有反应？
A: 请确保已正确设置PowerShell执行策略，或尝试右键选择"使用PowerShell运行"

### Q: 下载的壁纸质量如何？
A: 下载的是原始分辨率的高质量壁纸（通常为4K或更高）

### Q: 脚本会占用大量系统资源吗？
A: 不会，脚本只在运行时占用少量资源，完成后自动退出
